# Security policy

Please do not report security issues in a public issue. If GitHub private
security advisories are enabled for this repository, use the **Report a
vulnerability** link on the Security tab. Otherwise, contact the repository
maintainer through the private contact method listed in the repository profile.

Include the affected commit or release, reproduction steps, and the impact.
Please do not include credentials, personal data, or live user information in
reports. The public source build intentionally has no telemetry endpoint or
embedded service credentials.
